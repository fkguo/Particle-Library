Particle Library for Windows
============================

Run ParticleLibrary.exe to start the application. Keep ParticleLibrary.exe,
the DLL files beside it, and the complete data directory together.

The installer does not require administrator access and does not register an
uninstaller. To remove an installed copy, delete its installation folder and
the Particle Library shortcuts from the Start Menu and desktop.

The PDG snapshot is bundled in data\flutter_assets. The application stages
and verifies it on first launch. Notes, favorites, settings, and downloaded
reviews are stored separately in your Windows user profile.

If the application fails to start, restore the complete folder from the
installer or portable ZIP. Do not move or distribute the EXE by itself.
