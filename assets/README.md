# assets/

Download the PDG snapshot separately (64 MiB, CC BY 4.0) and place it here
before building:

```bash
cp /path/to/pdgall-2026.0.sqlite assets/pdgall-2026.0.sqlite
```

Download it from the official PDG API page:

```text
https://pdg.lbl.gov/2026/api/index.html
```

The direct file is:

```text
https://pdg.lbl.gov/2026/api/pdgall-2026.0.sqlite
```

It is excluded by `.gitignore`. Its SHA-256 must match
`c82dab0c0a7c5264f23508066cabb8df9eacc1dbfc83c8d20fade6053394ba8a`;
the app verifies this before opening the database.

At runtime the app stages the asset into its own application-support container,
verifies it, and then opens it read-only. If the file is missing, Flutter
reports an asset-packaging error during `flutter run`, `flutter test` or a
platform build.

Alongside the official snapshot, the repository ships two **derived, read-only**
databases:

- `pdg_notes_2026.sqlite` — the pdgLive enrichment sidecar (generated by
  `tool/fetch_pdg_notes.py`, `tool/fetch_pdg_reviews.py` and
  `tool/fetch_pdg_particle_status.py`):
  - 299 entry summaries, 39 of them with old-name (`was`) notes;
  - 209 pdgLive-cited references, all with INSPIRE record IDs and cite keys
    (266 citation links; 202 of the references also carry a DOI);
  - 67 entry-to-review links for 48 entries;
  - 341 particle-status marks: 189 1–4 star ratings from the pdgLive baryon
    group pages and 152 established bullets (`•`) from the meson group pages.
    The meson pages do not publish a star count, so their bullet is stored as
    `established = 1` and is never rendered as an invented star rating.
- `review_index_2026.sqlite` — page-level full-text index of the 121 PDG Review
  PDFs (generated by `tool/build_review_index.py`).

This sidecar covers the 209 references cited by the pdgLive notes. For other
official reference records, the app fetches keys from INSPIRE on demand. For
scope: the official
`pdgreference` table has 14,594 rows, of which 14,252 carry a numeric INSPIRE
recid (14,174 distinct; 342 have no recid), and it has no `cite_key` column.
This sidecar therefore stores cite keys only for the 209 pdgLive-cited records.
Other keys are fetched from INSPIRE on demand and cached in memory for the
session. Their source manifests and query rules are next to the
databases.

`brand/` contains the shared owl/Quark artwork used by the macOS Dock, app
header, favicon-style marks and idle animation.
