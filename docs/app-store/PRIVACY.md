# Particle Library — Privacy Policy

Last updated: 2026-10-22

Particle Library is a free, offline reader for the Particle Data Group (PDG)
Review of Particle Physics. It is not an official PDG application.

## Data we collect

The developer does not collect, sell, rent or share personal data through the
app. The app has no account system, analytics, advertising SDK, crash-reporting
SDK or telemetry, and the project does not plan to add analytics or account
services. If that ever changes, this policy and the App Store privacy answers
will be updated before the change ships.

## Data stored on your device

The following data stays on your device and is not sent to the developer:

- notes, collections, tags, favorites and recent searches;
- PDF highlights and annotation anchors;
- app settings and downloaded review PDFs;
- optional Zotero index data read through Zotero's local API.

Deleting the app removes this local data. You can export notes or a full backup
from Settings before deleting it.

## Network requests

The app makes network requests only when you use a feature that needs the
network:

- downloading official PDG review PDFs from `pdg.lbl.gov`;
- optionally fetching reference titles from Crossref (`api.crossref.org`);
- optional INSPIRE literature search (`inspirehep.net`);
- on Android/macOS, checking for a newer GitHub release
  (`cdn.jsdelivr.net`, `raw.githubusercontent.com`, `api.github.com`);
- App Store purchases are handled by Apple.

These services receive the request and your IP address according to their own
privacy policies. The developer does not receive or retain those requests.

On iOS, update checks use the App Store only; the app does not contact GitHub
for updates.

## Children

The app does not collect personal data from children.

## Changes

Material changes to this policy will be published in this document and in the
app repository.
