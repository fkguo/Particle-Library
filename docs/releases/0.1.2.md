# Particle Library 0.1.2

Free preview update for macOS and Android. There are no in-app purchases.

## New and improved

- **Mobile export works** — JSON notes, Markdown notes and full ZIP backups open
  the Android/iOS system share sheet. Import works on all platforms.
- **Full backup import** auto-detects ZIP or JSON, validates the backup version
  and merges notes without deleting current data.
- **Capture safety** — pressing Enter in the capture search no longer appends to
  the first unrelated note.
- **Cleaner search results** — global note hits use the current UI language and
  the same title/fallback rules as the Notes page.
- **MathML title search** — cleaned reference titles are searched when raw SQL
  cannot match text split across MathML nodes.
- **Full catalog everywhere** — desktop top bar and compact overflow menu.
- **iOS App Store update mode** — iOS builds never link to GitHub for updates;
  Settings reports that the App Store delivers updates.

## Fixed

- Highlight anchor removal persists; saved highlight ranges no longer clobber
  custom titles.
- Tapping a highlight opens its range handles directly; range save has error
  handling, desktop handles are enabled, and deletion asks for confirmation.
- Review anchor chips open the correct PDF page.
- Nested `K_{\ell4}` scripts, PDG Live-style multi-quark subscript spacing,
  quote-bearing default titles and incoming note-to-note backlinks are fixed.
- Spaced exotic-particle names stay whole; prose suffixes are not swallowed;
  neutral charge-zero shorthand is a superscript; `~` masses, decay
  multiplicities and text-only arrow tokens render correctly.
- Reference titles strip MathML/JATS markup safely, including pretty-printed
  MathML and literal comparison signs.
- No in-app purchases or Android Billing permission.
