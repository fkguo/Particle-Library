# Particle Library 0.1.1

Follow-up preview for macOS and Android.

Superseded by [0.1.2](0.1.2.md) and [0.1.3](0.1.3.md).

## New

- **Full backup / import** — one ZIP with settings, favorites, notes, highlight
  anchors and cached review PDFs. Import auto-detects the backup and merges
  notes without deleting current data. Export is available on desktop; mobile
  builds can import.
- **Full catalog everywhere** — the catalog is reachable from every primary tab
  (top bar on desktop, overflow menu on compact layouts).
- **Editable highlight ranges** — tapping a highlight selects it and exposes the
  two drag handles directly; save with the check button. Renamed highlight
  titles survive range edits.
- **Better update checks** — jsDelivr/raw GitHub manifest fallback for networks
  where the GitHub API is blocked, with `update.json` as the release manifest.

## Fixed

- Spaced exotic-particle descriptions such as `T_c c cbar cbar(6600)` stay one
  math unit; prose suffixes such as `MASS`/`MEAN LIFE` are no longer swallowed
  into subscripts.
- Neutral charge-zero shorthand (`B_s0`, `Xi_c0`, `Lambda_b0`, …) renders as a
  superscript, consistent with particle-symbol rendering.
- Reference titles clean JATS/MathML/MathML-namespaced markup, including
  pretty-printed MathML, square roots, fractions and superscripts; literal
  comparison signs such as `<sqrt(s)<` are preserved.
- Approximate masses use `\sim`; decay multiplicities no longer gain a comma;
  text-only decay tokens containing arrows are preserved.
- PDF highlight notes use the human review title in generated titles and bodies;
  comment/range edits no longer revert to the PDF filename.
- Anchor removal is persisted immediately and on close.
- Deleting a highlight asks for confirmation; desktop selection handles are
  enabled.
- Full catalog entry, title clamping/identifier-first defaults and several
  reference-title surfaces no longer show raw MathML/HTML.

## Verification

- `flutter test`: **198 tests passed**
- `flutter analyze`: clean
- macOS DMG/ZIP rebuilt from this tag; Android arm64-v8a and armeabi-v7a APKs
  rebuilt with the same snapshot.

## Known limitations

- macOS preview is ad-hoc signed, **not notarized**.
- iOS is development-signed only; App Store distribution needs a paid Apple
  Developer team.
- Android API 24 and 32-bit devices are built but not device-tested in this
  release.
- Full-backup export requires a file picker; mobile import works.
